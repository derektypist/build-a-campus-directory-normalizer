# Build a Campus Directory Normalizer

Creates lookup tables from nested data designed to perform fast and efficient searches

## Technologies

Uses JavaScript Objects and Loops.

## Deployment

Copy `script.js` into the text editor of your choice.  If using terminal, use the command `node script.js` to run the code.
